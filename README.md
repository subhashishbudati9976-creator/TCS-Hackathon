# AVENUE 🏦
> **AI-Powered Banking Branch Operations & Customer Experience Optimization Platform**

AVENUE transforms modern banking branch operations by connecting customer journeys, queue management, staff allocation, and predictive intelligence into a single cohesive platform.

---

## 🏗️ Architecture Stack

| Layer | Technology | Primary Role |
|---|---|---|
| **Frontend** | React + Vite (Vanilla CSS / Modern Design) | Responsive portals for Customers, Branch Managers, and Admins |
| **Backend** | Java 17+ / Spring Boot 3 | Enterprise business logic, JWT authentication, and REST APIs |
| **Database** | MySQL | Persistent store for branches, appointments, staff, and tokens |
| **AI / ML** | Python 3.10+ / FastAPI / scikit-learn | Wait-time prediction, demand forecasting, & digital twin simulation |
